# Play Chapter 1

Download `The_Last_Ward_Chapter_1_Play.zip`, extract it completely, then open
`The_Last_Ward_Chapter_1.html` in Chrome or Edge. Press Begin Investigation to
allow sound. Start a new game. No installation, server or internet is required.

The same standalone HTML is also available directly in this directory.
`The_Last_Ward_Chapter_1_Source.zip` is for source development: extract it and run
`python -m http.server 8010` in the project folder, then visit localhost:8010.

Saves belong to the browser/origin. Export a terminal record before changing browsers.
